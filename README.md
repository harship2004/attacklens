# AttackLens

Attack Simulation & Intrusion Detection Lab

An isolated virtual lab where common attacks are simulated and detected with
Suricata, with alerts shown on a custom Flask dashboard.

## Objectives
- Build an isolated attacker/victim lab (Kali Linux + Ubuntu)
- Simulate port scan, SSH brute force, SQL injection, XSS, and SYN flood
- Write custom Suricata rules and measure detection and false positives
- Build a Python parser and Flask dashboard with alert notifications

## Status
In progress

## Ethical Notice
All testing is done only in a self-owned, isolated virtual lab for educational purposes.
